TrustLoopGuard is a guardrail runtime that customers call **before** their AI agent's output reaches the outside world. It returns a verdict — `allow`, `block`, `rewrite`, or `escalate` — in milliseconds, with a structured reason and an audit trail.

```
agent proposes output → trustloop.check(...) → allow | block | rewrite | escalate → log
```

That single `check` call is the product. Everything in the repo exists to make that call fast, accurate, and auditable.
